# 📡 3D-Планировщик сотовой сети (LTE 1800 МГц)

Интерактивный 3D-симулятор радиопокрытия, направленных секторов антенн, интерференции и пропускной способности мобильной сети диапазона **LTE Band 3 (1800 МГц)**.

Разработано для наглядного изучения дисциплины **«Основы радиотехнологий»**.

---

## 🌟 Основные возможности

- **3D-город на Three.js (120+ FPS)**: процедурная генерация кварталов, зданий со светящимися окнами и анимация радиоволн.
- **Физическая модель затухания**:
  - Модель **COST-231 Hata** для городской застройки.
  - Формула свободного пространства **Фрииса** на малых расстояниях.
- **3-секторные антенны (3 × 120°)**:
  - Диаграмма направленности по стандарту **3GPP TR 36.814** (усиление 17 дБи по оси, ширина луча $\theta_{3дБ} = 65^\circ$).
  - Настройка азимута и высоты подвеса мачты (15–60 м).
- **Трассировка лучей (Ray-Tracing)**:
  - Автоматическое определение зданий на пути радиолуча к абоненту (каждое здание гасит сигнал на 5 дБ).
  - Подсветка зданий, вызывающих радиотень, при наведении курсора на карту.
- **Частотное планирование и SINR**:
  - 3 частотных канала: **Синий (F1)**, **Оранжевый (F2)**, **Фиолетовый (F3)**.
  - Учёт соканальной интерференции и теплового шума ($-97$ дБм).
- **Формула Шеннона**:
  - Расчёт пропускной способности с учётом полосы 10 МГц и количества подключённых абонентов на сектор.
- **Живой трафик**:
  - Абоненты перемещаются по улицам, огибая дома, и автоматически переключаются на лучшую соту (хэндовер).
- **Интерактивное обучение (Onboarding)**:
  - 6 пошаговых заданий для студентов с авто-проверкой действий.
- **Экономическая модель и оценка в звёздах**:
  - Расчёт бюджета оборудования (мачта, мощность, секторы).
  - Получение до ★★★ за качество покрытия, скорость и экономию бюджета.
- **Темы оформления**: Неоновый ночной режим и дневной режим.
- **Вкладка «Теория (с картинками)»**: наглядные SVG-графики и пояснения ключевых формул.

## 🚀 Запуск проекта

Проект не требует сборки и серверов. Достаточно открыть файл `index.html` в любом современном браузере:

```bash
# Клонирование репозитория
git clone https://github.com/Vitalikdeve/cellular-network-planner-3d.git

# Открытие файла
cd cellular-network-planner-3d
# Откройте index.html в Google Chrome, Firefox, Edge или Safari
```

## 🎮 Управление

- **ЛКМ + перемещение мыши**: вращение 3D-камеры (орбита).
- **Клик по земле**: установка новой базовой станции.
- **Клик по станции**: выбор и открытие панели настройки параметров.
- **Перетаскивание станции**: перемещение БС по карте.
- **Колесо мыши / жест щипка на смартфонах**: зуммирование.
- **Клавиши 1, 2, 3**: быстрое переключение уровней (Село, Городок, Плотный город).
- **Пробел**: включение/выключение движения абонентов (живой трафик).
- **Delete / Backspace**: удаление выбранной станции.
- **Escape**: сброс выбора или закрытие подсказок.
